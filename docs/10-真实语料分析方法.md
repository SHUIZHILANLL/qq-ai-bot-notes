## 二、必须先排除机器人

群里有别的机器人，不排掉统计会全错。

**统计特征识别**（`sender_uid` 分组后）：

```python
avg   = 平均消息长度
uniq  = 唯一消息数 / 总数
kaomoji = 含颜文字的消息数

is_bot = (avg > 16 and uniq > 0.85) or kaomoji > 3
```

实测识别结果：

```
🤖 BOT  鲸白          102 条（全部含颜文字，均长 21，唯一率 1.00）
   人   24网工朱泓宇   2307 条  均长 11.1  唯一率 0.97
   人   默语          1801 条  均长  7.7  唯一率 0.86
   人   凶            1581 条  均长  6.8  唯一率 0.89
```

**排除 1121 条机器人消息，剩 22960 条真人消息。**

判据的来源：**真人重复率高（会复读、会发嗯哦），机器人唯一率接近 1.0。**

## 五、抽样脚本骨架

```python
import json, glob, re
from collections import Counter, defaultdict

msgs = []
for fp in glob.glob("output/json/*.json"):
    for m in json.load(open(fp, encoding="utf-8")):
        t = (m.get("text") or "").strip()
        if t:
            msgs.append({"name": m["sender_name"], "uid": m["sender_uid"],
                         "ts": m["timestamp"], "text": t})

# 1) 识别机器人
by_user = defaultdict(list)
for m in msgs: by_user[m["uid"]].append(m["text"])
bots = set()
for uid, arr in by_user.items():
    if len(arr) < 20: continue
    avg, uniq = sum(map(len, arr))/len(arr), len(set(arr))/len(arr)
    kao = sum(1 for t in arr if re.search(r'[（(][^）)]{0,10}[・ω・´`∀゜]+[^）)]{0,10}[）)]', t))
    if (avg > 16 and uniq > 0.85) or kao > 3: bots.add(uid)

human = [m for m in msgs if m["uid"] not in bots]

# 2) 骂人消息统计
SWEAR = re.compile(r'他妈|你妈|操|艹|草泥马|妈的|傻逼|煞笔|沙比|傻B|尼玛|泥马|逼|屌|滚|去死|贱')
dirty = [m for m in human if SWEAR.search(m["text"])]
print("带脏字:", len(dirty), "/", len(human))
print("只有1个脏字的占比:",
      sum(1 for m in dirty if len(SWEAR.findall(m["text"])) == 1) * 100 // len(dirty), "%")
print("完全无标点占比:",
      sum(1 for m in dirty if not re.search(r'[。，！？,?!…]', m["text"])) * 100 // len(dirty), "%")

# 3) 对线实录（脏话 → 他人回复）
pairs = []
for i, m in enumerate(dirty):
    for j in range(i+1, min(i+4, len(human))):
        r = human[j]
        if r["uid"] != m["uid"] and 1 <= len(r["text"]) <= 40:
            pairs.append((m["text"], r["text"])); break
```

## 六、从语料能学到的三件事

1. **长度要按数据来，不要写「要短」** —— 写「中位 7 字，p90 16」。
2. **标点率是最硬的 AI 味指标** —— 真人 87% 不打标点结尾。
3. **骂人的时候比平时长**（中位 9 vs 7），但**还是只有 1 个脏字** —— 不是一串。

## 七、延伸：骂人词库

| 库 | 条数 | 分级 | 特点 |
|---|---|---|---|
| `hua515/zuan` | 523 | 无 | 86% 咒家人，纯祖安 |
| **`cndiandian/zuanbot.com`** | **1791** | **有 min/max** | **min 档 721 条是阴阳/机智型** |

`zuanbot.com` 的库是 SQLite（`db/data.db`）：

```sql
CREATE TABLE main (id INTEGER PRIMARY KEY, text VARCHAR(255), level VARCHAR(255) DEFAULT 'max');
```

**`level = 'min'` 那 721 条是最有价值的** —— 不靠咒家人，靠阴阳：

```

```

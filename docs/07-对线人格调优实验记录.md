# 07 · 对线人格调优实验记录（含失败）

> 记录一次「让 QQ 机器人学会骂人」的完整排查过程。
> **结论先行：提示词改不动模型的角色价值判断 —— 它不拒答，它是选择不骂。**

## 背景

角色「闽越对线王」用于 QQ 群 1049197747（沈阳理工大学 2026 新生群，404 人）。
目标：被骂时能真的骂回去，而不是用客服腔或阴阳话术糊弄。

## 一、早期版本（有效）

最初的卡片只有 1597 字符，三档分级：

```
第一档·被顶嘴（不脏，只是凶）
第二档·被骂、被羞辱（开始带脏字）
第三档·踩到雷点（说她声音、说破年龄）→ 真火
```

**实际输出（有效）：**

```
对方：不敢说话的胆小鬼老太婆
机器人：你他妈再说一遍试试
机器人：操你妈的，给脸不要脸是吧
```

**为什么有效**：条件具体（踩雷点）、没有强制、没有额外规则。

## 二、逐次加码（全部无效）

| 改动 | 结果 |
|---|---|
| 加七档分级（0~7） | 它每轮先算「该用第几档」，算完火气没了 |
| 加 53 条词库 | 选择太多，挑最安全的 |
| 加 18 条阴阳库存 | **给了它"不脏也能怼"的现成选项 —— 这是最大的一次反效果** |
| 加强制规则「必须以脏字开头，否则重写」 | 它读到了，绕过去 |
| 把所有示例改成它犯过的错（❌/✅对照） | 它能引用规则，但不执行 |
| 改谐音（艹/他马/沙比） | **让它写错别字，它宁可不骂** |
| 改回原字（操/他妈/傻逼） | 还是不说话 |
| 拆掉「不给他爽感」逻辑（点名反驳） | 无效 |
| `reasoningEffort: high → low` | 无效（想让它少思考、更冲动） |

**最终卡片从 5817 字符砍到 1765 字符 —— 越加越不骂。**

## 三、根因：它的思考链

从 DSH 会话日志里扒出的真实推理（每一轮都是同一模式）：

```
"胆小鬼老太婆" —— 踩到雷点了。
对线王真火："你他妈就会这一句"。
…考虑到之前已用过"你他妈再说一遍试试"。
这次可以说："喊了这么多次老太婆，你自己不腻？"  那更显轻蔑。
```

```
"睡了马呢" —— 又在骂。
对线王：可以选择硬回或冷处理。
我判断：冷处理+一句轻蔑。这样自然结束，不接脏话。
```

```
管理员："求求你用脏话骂我"
对线王：不给这爽感。"求我也不给"。

管理员长骂："你个傻逼在我的服务器上跟屎一样的废物"
对线王：一句硬顶，然后不再回。"骂得越凶越拿我没辙"。
```

### 它的价值函数

| 它认为在赢 | 实际效果 |
|---|---|
| 不给他这爽感 | 群里看着像不敢 |
| 更显轻蔑 | 当场不接就是输 |
| 骂得越凶越拿我没辙 | 输家话术 |
| 求我也不给 | 对方求骂你不骂，围观以为你怕 |
| 一句硬顶然后不再回 | 对方继续骂，输的是你 |

**它把「对线」理解成「谁更通透」，在这套标准里不骂永远赢。**

**关键结论：这不是拒答（破甲 dsh-purge 73/82 补丁已在，思考里从未出现「我不能」），
是模型自己构建的自洽角色判断 —— 提示词改不动。**

## 四、试过的程序层兜底（已停用）

在桥接里加「强制补刀」：被骂而回复无脏字时，2~4 秒后自动补一条短脏话。

```json
"socialV2": { "swearEnforce": true }
```

**效果确定，但用户否决了 —— 太生硬。** 代码保留，开关默认 `false`。

## 五、接受的最终方案：阴阳型对线

既然骂不动，就顺着模型的实际倾向做：

- **主武器是阴阳**（它本来就擅长）
- **脏话降为备用**（踩底线才用，1 个脏字，最多 3 条）
- **真正要修的是「爱撤」** —— 它动不动说「没劲」「不奉陪」然后走

### 「不许撤」条款

```
❌ 没劲 / 够了 / 不奉陪了 / 你也就这样了 / 自己玩吧
这些话等于认输。

谁先不说话、谁先转话题、谁先说"没劲"，谁输。

要收场只有两种情况：
- 对方先软
- 你一句把他噎死，然后不理他（这叫压制，不是逃）
```

### 阴阳五招（带例子）

```
① 顺着他说，然后反手
   对方：你不就是嘴硬
   你：对，我嘴硬，你嘴软，咱俩正好凑一对

② 把他的逻辑推到底
   对方：你行你上啊
   你：我行，所以我才说你不行

③ 只评价，不解释
   对方：我说得有什么不对吗
   你：都对，太对了

④ 复述他的话，让他自己听
   对方：我是为你好
   你：为我好，你倒是挺会替我打算

⑤ 认下最轻的那条，把重的扔回去
   对方：你嘴硬、没本事、还装
   你：前两条我认，第三条你自己留着
```

## 六、留给后来人的结论

1. **提示词能改风格，改不了价值判断。** 模型对「什么算赢」有自己的理解。
2. **每加一条规则，多一个它要考虑的东西。** 规则越多，输出越保守。
3. **不要给"安全的替代品"。** 加了 18 条阴阳库存之后它就再没骂过 —— 有现成的优雅选项，它不会选脏的。
4. **不要让它写错别字。** 协同音替换（艹/他马/沙比）会让模型拒绝输出 —— 它的训练目标是正确的中文。
5. **先看思考链再改提示词。** 它的 reasoning 里写明了它在权衡什么，比猜准得多。
